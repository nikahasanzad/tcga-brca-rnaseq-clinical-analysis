# Future methodological chapter outline

This is a future teaching proposal derived from the notebook, not evidence of Springer Nature acceptance, a delivered chapter or an externally tested protocol.

| Section | Inputs and outputs | Worked example or pitfall |
|---|---|---|
| Define the question | Unit, predictor, outcome and permissible claim | Age at diagnosis is not a within-patient ageing trajectory |
| Inspect clinical records | One primary diagnosis per participant | Flattened rows are not independent patients |
| Curate molecular observations | Participant-specimen-aliquot mapping | More files do not mean more independent observations |
| Establish the count contract | Count field, ordered IDs and manifest | Matching dimensions alone does not establish alignment |
| Screen sample quality | Technical and expression-space diagnostics | A single tail flag is not an automatic exclusion |
| Filter and transform | Design-aware filter, TMM and voom | TMM factors are not quality scores; E and weights differ |
| Fit associations | Continuous Age and categorical Stage | Omnibus inference has no single direction |
| Integrate and prioritize | Common universe and explicit selection | 479 Joint Both is not the same set as 418 retained Both |
| Visualize honestly | Units, denominator and color encoding | Figure 9 colors are not comparable across columns |
| Report and reproduce | Code version, environment and hashes | Local repeatability is not clean-install or external validation |

Each step should specify purpose, input, action, output, verification and common failure. A chapter would need primary references, tested examples, reader prerequisites and publisher-specific requirements. The historical explanatory text is preserved in the separate compendium, including superseded sketches with correction notes.
