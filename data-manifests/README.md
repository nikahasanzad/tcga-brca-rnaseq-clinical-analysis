# Archived GDC file manifests

Two standard download TSVs contain id, filename, md5, size and archived state.
The final set has 1,093 files; technical QC has ten, with five overlaps.
All 1,111 discovery records in the source export were marked open/released.
These are file-level metadata, not clinical or patient-to-file mappings.
See ../docs/INPUT_DATA.md and ../docs/IDENTIFIERS_AND_DATA_USE.md.
Access/availability today was not tested for every UUID. Source conditions and
acknowledgment remain applicable; no third-party data license is replaced.
metadata_input_fingerprints.csv identifies the private historical exports needed
to reconstruct cache metadata and verify the clinical TSV.
