# Attribution and third party material

TCGA-BRCA data were generated by the TCGA Research Network and accessed through
the NCI Genomic Data Commons. Acknowledge the contributors and repository when
presenting the results. [GDC access policy](https://gdc.cancer.gov/access-data/data-access-policies)
requires appropriate dataset/repository acknowledgment and prohibits attempts at
participant re-identification. Controlled data require separate authorization.

This repository includes original project scripts, project-derived aggregate/gene
tables and figures, and a text form of the project's frozen syntax fixture.
It excludes the historical notebook, article text, raw human-subject records,
GDC cache objects, clinical data and installed R package implementations.
The three methodological papers are cited in docs/REFERENCES.md; no paper text
or publisher figures are redistributed.

R packages retain their own licenses. environment/third_party_package_licenses.csv
records installed DESCRIPTION license strings only where recorded versions match;
it is not a grant for source data or a complete legal compatibility opinion.
The renv packaging tool is not an original analytical dependency and its source
archive is kept local. The public lock records observed installed packages.
